# Numbers

A gentle, playful maths game designed to help young learners build number confidence, including children with dyscalculia.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To make a production build, run `npm run build`.

## What’s inside

- Child profiles with a name, age, and avatar. A grown-up can create and switch between profiles.
- Three short activities: counting, comparing groups, and number order.
- Five questions per game, with positive feedback and a progress summary.
- Optional spoken prompts using the browser’s built-in speech synthesis.
- Progress saved in the current browser on the current device using local storage.
- Responsive layout, keyboard focus styles, accessible labels, and reduced-motion support.

## Privacy note

Profiles and progress are stored only in this browser on this device. There is no account service or cloud sync. Avoid entering sensitive personal information.
